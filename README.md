# World Cup 2026 Predictor

A World Cup prediction and simulation platform inspired by Joachim Klement's forecasting model.

## Features

- Match simulation
- Tournament simulation
- Elo ratings
- Monte Carlo predictions

## Tech Stack

- Python
- FastAPI (future)
- PostgreSQL (future)
- React (future)

## World Cup 2026 Predictor

## Version 1 Features:
- Team simulation
- Match simulation
- Knockout tournament
- Randomized brackets
- Champion prediction

## Version 1 Assumptions:
- Match outcomes depend only on team strength (rating)
and randomness.

- Higher-rated teams have a higher probability
of winning, but upsets remain possible.

- Knockout format
